5. 컨테이너 구성

EC2에서는 다음 컨테이너가 Docker Compose로 실행된다.

서비스imageport비고
house-inventory-front yangyag2/house-front:latest 8085:80 -
house-inventory-back yangyag2/house-back:latest internal 8080 SPRING_DATASOURCE_URL은 .env의 DB_HOST / DB_NAME / DB_SCHEMA에서 조립됨

postgres 토폴로지

yangyag-postgres는 별도의 외부 인프라(다른 Docker Compose)로 운영되는 공유 PostgreSQL이다. 이 프로젝트의 docker-compose.yml에는 postgres 서비스가 정의되지 않으며, house-inventory-back은 house-inventory_default 네트워크를 통해 yangyag-postgres 호스트명으로 접속한다. yangyag-postgres는 이 네트워크에 수동으로 attach되어 있다.

6. 배포 명령

프론트만 변경한 경우

docker build -t yangyag2/house-front:latest ./front
docker push yangyag2/house-front:latest

./aws/connect.sh
cd /home/ubuntu/house-inventory
docker compose pull front
docker compose up -d front

백엔드만 변경한 경우

docker build -t yangyag2/house-back:latest ./back
docker push yangyag2/house-back:latest

./aws/connect.sh
cd /home/ubuntu/house-inventory
docker compose pull back
docker compose up -d back

전체 재기동

./aws/connect.sh
cd /home/ubuntu/house-inventory
docker compose pull
docker compose up -d
주의

EC2에서는 --build를 쓰지 않는다. 이미지는 항상 Docker Hub에서 pull한다.

8. DB 스키마

  • house 역할(user)은 yangyag-postgres의 auto DB의 house 스키마에 한정된 권한을 갖는다.
  • yangyag-postgres는 host 127.0.0.1:5432 바인딩으로 실행되어 외부 노출이 없다.
  • 비밀번호 등 실제 값은 EC2의 /home/ubuntu/house-inventory/.env에 보관되며 git에 들어가지 않는다.

auto DB에 house 역할과 house 스키마를 만드는 SQL 예시

DO $$
BEGIN
  IF NOT EXISTS (SELECT FROM pg_roles WHERE rolname = 'house') THEN
    CREATE ROLE house LOGIN PASSWORD '<강한_비밀번호>';
  END IF;
END$$;

CREATE SCHEMA IF NOT EXISTS house AUTHORIZATION house;

GRANT CONNECT ON DATABASE auto TO house;
GRANT USAGE, CREATE ON SCHEMA house TO house;
ALTER DEFAULT PRIVILEGES FOR ROLE house IN SCHEMA house GRANT ALL ON TABLES TO house;
ALTER DEFAULT PRIVILEGES FOR ROLE house IN SCHEMA house GRANT ALL ON SEQUENCES TO house;

9. 백업 / 복구 메모

기존 standalone postgres에서 외부 공유 postgres로 전환할 때 받아 둔 SQL 두 파일이 EC2 호스트에 보존되어 있다.

  • /home/ubuntu/house-items-ec2.sql — 전체 DB pg_dump
  • /home/ubuntu/house-items-ec2-house.sql — house 스키마 한정 dump

기존 standalone postgres 볼륨은 검증 후 정리되어 더 이상 존재하지 않는다. 향후 복구 필요 시 호스트의 백업 SQL 파일을 yangyag-postgres의 auto DB house 스키마에 적재한다.

10. 주의

  • SSH private key(aws/test-keypair.pem)는 *.pem gitignore로 제외한다. 저장소에는 접속 스크립트만 올린다.
  • Docker Hub 비밀번호, 토큰, 개인 인증 정보는 문서와 저장소에 기록하지 않는다.
  • .env는 .gitignore 대상이라 git에 들어가지 않는다. EC2에 직접 보관한다.
